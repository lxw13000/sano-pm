# SANO Jackpot中奖机制专项

本目录集中管理SANO Jackpot中奖机制优化相关的产品需求、维护规则和管理端页面原型。本阶段包含Markdown需求文档及管理端SVG、PNG设计图，不包含客户端原型、数据库设计、接口设计和测试用例。

## 当前设计主线

本次优化以“每轮随机规则快照”为核心：

- 上一轮奖金结算完成后，以`max（奖池剩余值，配置最小值）`至配置最大值作为区间，生成下一轮随机绝对开奖阈值。
- 生成阈值时，同时按权重随机选择一套消费价值倍率模板，并随机选择本轮奖金比例。
- 一次赠送请求只执行一次中奖判断，按照该请求的实际消费总价值匹配倍率。
- 奖池达到随机阈值后沿用现有出奖实现；中奖奖金按照实际中奖时的奖池金额计算。
- 本轮随机参数生成后锁定，直到本轮开奖完成；下一轮重新生成。
