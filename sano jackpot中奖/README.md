# SANO Jackpot中奖机制专项

本目录集中管理SANO Jackpot中奖机制优化相关的产品需求、维护规则和管理端页面原型。本阶段包含Markdown需求文档及管理端SVG、PNG设计图，不包含客户端原型、数据库设计、接口设计和测试用例。

## 当前设计主线

本次优化以“每笔消费请求独立随机”为核心：

- 每笔幸运礼物消费成功入池后，在配置最小值至最大值之间独立生成本次随机绝对阈值。
- 本次奖池金额达到随机阈值后，再按权重随机选择一套消费价值倍率模板；奖金比例配置在模板各消费区间中。
- 一次赠送请求只执行一次中奖判断，按照该请求的实际消费总价值匹配模板区间、倍率和中奖比例。
- 模板和区间参数计算完成后判断白名单；白名单用户跳过倍率和随机命中，按100%中奖率竞争原子中奖锁。
- 中奖奖金按照实际中奖时的奖池金额乘以命中区间中奖比例计算。
- 不预生成或长期锁定开奖参数；不同用户、不同请求的阈值和模板均可不同。
