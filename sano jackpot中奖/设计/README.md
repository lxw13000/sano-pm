# SANO Jackpot管理端页面原型

## 原型说明

- 管理端页面共7张，统一为1672×941。
- `原型图/`中的PNG用于评审和分享。
- `源文件/`中的SVG作为可编辑设计源文件。
- 页面数据为原型示例，不代表线上真实配置。

## 页面列表

1. [Jackpot配置列表](原型图/01-管理端-Jackpot配置列表.png)：每行提供“修改”“明细配置”和“当前周期”入口。
2. [Jackpot明细配置](原型图/02-管理端-Jackpot明细配置.png)：上半部分配置随机阈值最小值和最大值，并按`max（剩余值，最小值）～最大值`展示下一轮有效随机范围；下半部分左侧为倍率模板卡片，右侧为所选模板的消费区间倍率和中奖比例。
3. [新增倍率模板弹窗](原型图/03-管理端-新增倍率模板弹窗.png)：在当前明细配置页上居中弹出，填写模板名称、抽取权重和是否默认，创建后自动选中新模板。
4. [编辑倍率模板弹窗](原型图/04-管理端-编辑倍率模板弹窗.png)：复用新增弹窗结构，回显模板数据；保存仅影响后续新轮次。
5. [新增消费区间行内编辑](原型图/05-管理端-新增消费区间行内编辑.png)：点击“新增区间”后在表格底部直接增加编辑行，录入上限值、倍率和中奖比例。
6. [编辑消费区间行内编辑](原型图/06-管理端-编辑消费区间行内编辑.png)：点击目标行“编辑”后，仅该行进入编辑态，保存或取消均在当前行完成。
7. [当前周期弹窗](原型图/07-管理端-当前周期弹窗.png)：从配置列表打开，只读展示正在使用的开奖阈值、奖池实际余额、消费倍率模板及区间快照，以及本周期是否存在白名单和名单明细。

## 交互选择

- 模板字段少且属于独立对象，新增、编辑统一采用居中弹窗，避免跳离当前模板与区间配置上下文。
- 消费区间字段与表格列一一对应，新增、编辑采用行内操作，减少弹窗层级并让上下限顺序更容易核对。
- “实际中奖概率”和“奖金计算”均为系统实时计算的只读结果，运营只填写消费价值上限、倍率和中奖比例。
- 区间统一使用“≤ 上限值”表达，包括最后一档；保存时校验上限唯一且递增。

## 当前页面关系

```text
Jackpot配置列表
├─ 每行“当前周期”
│  └─ 当前周期弹窗：开奖参数、奖池余额、模板区间、白名单状态及名单
└─ 每行“明细配置”
   └─ Jackpot明细配置
      ├─ 奖池阈值配置
      └─ 单次消费区间倍率配置
         ├─ 左侧：模板1、模板2、模板3及默认状态
         │  └─ 新增/编辑模板：居中弹窗
         └─ 右侧：消费价值上限、倍率、中奖比例、实际中奖概率
            └─ 新增/编辑区间：表格行内编辑
```
