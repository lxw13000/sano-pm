# SANO Jackpot管理端页面原型

## 原型说明

- 管理端页面共10张，统一为1672×941。
- `原型图/`中的PNG用于评审和分享。
- `源文件/`中的SVG作为可编辑设计源文件。
- 所有SVG均为独立文件，页面底图和弹窗节点已经内联，不依赖同目录下的其他SVG；可直接导入Figma并继续编辑。
- 页面数据为原型示例，不代表线上真实配置。

## 页面列表

1. [Jackpot配置列表](原型图/01-管理端-Jackpot配置列表.png)：每行提供“修改”“明细配置”和“白名单”入口。
2. [Jackpot明细配置](原型图/02-管理端-Jackpot明细配置.png)：上半部分配置随机阈值最小值和最大值，并展示每笔消费请求独立使用的随机范围；下半部分左侧为倍率模板卡片，右侧为所选模板的消费区间倍率和中奖比例。
3. [新增倍率模板弹窗](原型图/03-管理端-新增倍率模板弹窗.png)：在当前明细配置页上居中弹出，填写模板名称、抽取权重和是否默认，创建后自动选中新模板。
4. [编辑倍率模板弹窗](原型图/04-管理端-编辑倍率模板弹窗.png)：复用新增弹窗结构，回显模板数据；保存后从后续进入开奖流程的消费请求生效。
5. [新增消费区间行内编辑](原型图/05-管理端-新增消费区间行内编辑.png)：点击“新增区间”后在表格底部直接增加编辑行，录入上限值、倍率和中奖比例。
6. [编辑消费区间行内编辑](原型图/06-管理端-编辑消费区间行内编辑.png)：点击目标行“编辑”后，仅该行进入编辑态，保存或取消均在当前行完成。
7. [白名单管理－有效名单](原型图/08-管理端-白名单管理-有效名单.png)：维护当前有效的一次性优先中奖权益，支持查询、新增和移除。
8. [白名单管理－名单记录](原型图/09-管理端-白名单管理-名单记录.png)：只读查询白名单权益的完整生命周期，展示权益来源、加入原因、创建人、结束方式及关联中奖流水。
9. [新增白名单用户弹窗](原型图/10-管理端-新增白名单用户弹窗.png)：查询并确认用户，填写权益来源和加入原因后立即生效。
10. [移除白名单用户弹窗](原型图/11-管理端-移除白名单用户弹窗.png)：展示待移除用户信息并强制填写移除原因，操作结果写入名单记录。

## 交互选择

- 模板字段少且属于独立对象，新增、编辑统一采用居中弹窗，避免跳离当前模板与区间配置上下文。
- 消费区间字段与表格列一一对应，新增、编辑采用行内操作，减少弹窗层级并让上下限顺序更容易核对。
- “实际中奖概率”和“奖金计算”均为系统实时计算的只读结果，运营只填写消费价值上限、倍率和中奖比例。
- 区间统一使用“≤ 上限值”表达，包括最后一档；保存时校验上限唯一且递增。
- 白名单管理采用“有效名单 / 名单记录”页签分离当前操作与历史审计；新增使用弹窗，移除使用带必填原因的二次确认弹窗。

## 当前页面关系

```text
Jackpot配置列表
├─ 每行“白名单”
│  └─ 白名单管理
│     ├─ 有效名单：新增、查询、移除
│     │  ├─ 新增白名单用户弹窗
│     │  └─ 移除白名单用户确认弹窗
│     └─ 名单记录：来源、原因、创建人、结束方式及关联中奖流水
└─ 每行“明细配置”
   └─ Jackpot明细配置
      ├─ 奖池阈值配置：每笔请求独立使用MIN～MAX随机范围
      └─ 单次消费区间倍率配置
         ├─ 左侧：模板1、模板2、模板3及默认状态
         │  └─ 新增/编辑模板：居中弹窗
         └─ 右侧：消费价值上限、倍率、中奖比例、实际中奖概率
            └─ 新增/编辑区间：表格行内编辑
```
