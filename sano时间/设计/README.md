# SANO Time 移动端页面原型

本版包含 3 张 390×844 移动端页面与状态原型，沿用 SANO 个人中心的紫粉渐变、白色功能卡片、橙色当前导航和轻量信息组件。输出方式与 `sano公会运营` 一致：PNG 评审图、SVG 源文件、原型导航及生成工具。

## 查看入口

- [原型导航](原型导航.html)：浏览全部状态，打开 PNG 大图或 SVG。
- [全部状态总览](原型图/00-原型总览.png)：3 张状态横向总览。
- [个人中心默认态](原型图/01-个人中心-SANO时间.png)：建议优先评审的主方案。
- [需求设计文档](../需求文档/SANO时间.md)：产品规则、同步方式和验收标准。

## 页面清单

| 编号 | 页面/状态 | 评审重点 |
| --- | --- | --- |
| 01 | 个人中心 · SANO时间 | 时间条位于社交数据与资产卡片之间；完整显示年月日时分秒，信息明确但不抢主业务入口 |
| 02 | SANO时间说明弹层 | 解释 UTC+8、适用业务和设备时区不会改变 SANO Time；不展示本地换算 |
| 03 | SANO时间同步异常 | 无法取得服务端时间时不使用设备时间兜底，提供明确状态及重试入口 |

## 视觉与交互说明

- 主时间格式固定为 `YYYY-MM-DD HH:mm:ss`，采用 24 小时制。
- 标签统一为 `SANO TIME · UTC+8`；不使用 Beijing Time、System Time 或 Local Time。
- 默认态整条时间组件可点击，进入说明弹层。
- 说明弹层点击关闭、遮罩或 `Got it` 返回默认态。
- 异常态点击 `Retry` 返回正常态，仅用于表达状态流转。
- SVG 中主要跳转可点击；所有头像、金额和账号均为虚构示例。

## 输出说明

- `原型图/`：3 张 PNG 评审图及 1 张总览图。
- `源文件/`：3 张可编辑 SVG 源文件。
- `生成工具/`：SVG、导航和 PNG 的生成/渲染脚本及页面清单。
- `资源/需求输入/`：保留用户提供的个人中心截图作为只读设计参考。

## 重新生成

在 `sano时间` 目录执行：

```powershell
.\设计\生成工具\generate-prototypes.ps1
.\设计\生成工具\render-prototypes.ps1
```

生成工具只写入本项目的 `设计/` 目录。渲染使用本机已有 Node.js 和 sharp。
