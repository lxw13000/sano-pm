本项目用于明确 SANO 全球用户共同使用的官方平台时间。平台结算、每日重置、活动周期、榜单与有效时长均以固定的 `SANO Time（UTC+8）` 为准；不根据设备、IP或用户所在地自动换算本地时间。

本版原型包含个人中心默认态、时间说明弹层和同步异常态。设计产物沿用 `sano公会运营` 的目录规范，提供 PNG 评审图、SVG 源文件、原型导航和可重复生成工具。
