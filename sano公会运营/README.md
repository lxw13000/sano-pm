当前原型为25张桌面管理后台页面与状态，采用PNG评审图、SVG源文件及配套生成工具的形式。首页、列表和画像以“公会性质＋一句话结论＋关键依据”为主信息；5个主模块、7个画像标签，三类评估统一在评估中心。页面数据为虚构示例，仅供需求与交互评审。

`资源/需求输入/`保留原始需求、周榜奖励配置和业务枚举。相关资料参考以只读方式使用；本项目产物集中在本目录内。

原型22—25为07“分层与奖励”右侧抽屉的四种Tab状态，不是独立页面；Tab在分类汇总上方，关闭后回到07。
