当前原型为31张桌面管理后台页面与状态，采用PNG评审图、SVG源文件及配套生成工具的形式，按用户任务体系的业务层级规则命名。以“先看自己的盘子 → 比较公会 → 查看具体公会”为主线：工作台按角色自动汇总收益、平台贡献、主播结构、发展趋势和Top10；列表支持经营比较，详情保留性质与依据。5个主模块、7个画像标签，三类评估统一在评估中心。页面数据为虚构示例，仅供需求与交互评审。

`资源/需求输入/`保留原始需求、周榜奖励配置和业务枚举。相关资料参考以只读方式使用；本项目产物集中在本目录内。

分层与奖励的五张奖励明细图为同一右侧抽屉的五种Tab状态，不是独立页面；Tab在分类汇总上方，关闭后回到父页。其他主播奖励和子公会分层贡献筛选复用现有布局。默认正式周评估，审核进度和人工结论分开显示，旧编号迁移对照见设计说明。


本公会自身收益拆为直属主播贡献、直属子公会贡献和公会奖励；公会奖励来源明确为公会周榜、超级主播达标及其他来源。主播本人奖励不参与任何公会分层，贡献最多上行一层差额。详情见设计说明及需求文档第13.3、13.4节。


管理者与运营者复用工作台；运营者默认只看自己负责的公会，权限贯穿汇总、排名、列表和下钻。三张角色状态演示我的工作台/列表及运营者公会详情；三个Top10平铺展示各自指标，仅提供进入对应公会画像的详情操作，不增加主模块。
