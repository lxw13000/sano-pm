# 盲盒利润与概率计算工具

## 计算口径

- 金币与钻石按1:1等值。
- 赠送他人时，接收人获得返奖价值的70%。
- 接收人有公会时，公会额外获得接收人收益的20%。
- 自己玩时，购买者获得全部返奖价值，主播获得实际消费的2%。
- 主播有公会时，公会额外获得主播收益的20%。
- 输出是长期理论期望，不执行平台实际的逐笔最小单位取整。

## 1. 利润率分析

配置文件：[profit_analysis.yml](./profit_analysis.yml)

```powershell
python analyze_profit.py profit_analysis.yml
```

必填配置：

```yaml
gift_price: 20000
values: [9000, 20099, 41111, 60000, 140000]
probabilities: [60%, 28%, 6%, 4.8%, 1.2%]
```

脚本输出以下四种场景的期望支出、利润和利润率：

1. 赠送他人，无公会。
2. 赠送他人，有公会且按最高20%。
3. 自己玩，主播无公会。
4. 自己玩，主播有公会且按最高20%。

## 2. 概率计算

配置文件：[probability_calculation.yml](./probability_calculation.yml)

```powershell
python calculate_probabilities.py probability_calculation.yml
```

必填配置：

```yaml
gift_price: 20000
values: [9000, 20099, 41111, 60000, 140000]
value_return_rate: 96.988806%
```

价值返奖率按“盲盒期望价值÷礼物单价”填写，支持`96.988806%`或`0.96988806`格式。脚本按“礼物单价×价值返奖率”计算目标期望价值。

仅凭价值数组和价值返奖率不能唯一确定每个价值的概率。例如5个价值对应5个未知概率，但业务条件只能确定概率合计与价值期望。脚本先使用最大熵原则生成结果，再按10000概率基数取整，得到唯一且可复现的一组概率。

生成概率统一使用万分位精度：概率小数最多4位，百分比最多2位，最小概率步长为`0.0001`（即`0.01%`）。取整后概率合计严格为100%，实际返奖率可能与目标返奖率存在微小偏差，脚本会同时输出两者供核对。

如果目标期望价值不在价值数组的最小值与最大值之间，脚本会拒绝计算并输出原因。

## 概率格式

分析脚本支持以下三种等价写法，且每项概率必须符合万分位精度：

```yaml
probabilities: [60%, 28%, 6%, 4.8%, 1.2%]
probabilities: [0.60, 0.28, 0.06, 0.048, 0.012]
probabilities: [60, 28, 6, 4.8, 1.2]
```

例如`0.2352`等于`23.52%`，允许使用；`0.2352053488`超出万分位精度，不允许使用。

配置解析使用脚本内置的简化YAML读取器，仅支持当前示例所示的顶层字段和数组，不需要安装PyYAML。
