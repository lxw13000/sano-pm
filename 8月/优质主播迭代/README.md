# 主播身份体系迭代原型

## 原型说明

- 管理端页面状态：11张，统一为 1672×941（其中主播身份审核弹窗为成员页的操作状态）。
- App H5：7张，统一为 941×1672。
- SVG 文件为可编辑源文件，PNG 文件用于评审与分享。
- 页面中的主播、周期、奖励和任务数据均为原型示例数据。

## 信息架构

- 主播体系配置
  - 主播身份
  - 任务库
- 主播身份成员
- 周任务审核
- 奖励领取记录

任务库内部只保留一层业务页签：`任务项列表 / 任务模块`。主播身份与任务库是左侧菜单，不在内容区重复展示。

## 配置关系

1. 主播身份关联多个任务模块。
2. 任务模块关联多个任务项，并配置模块图标、名称、奖金、启用状态和备注。
3. 一个任务项对应一个技术实现，由技术维护任务编码、执行器和任务参数 JSON；运营只管理任务项、任务模块和主播身份之间的关联。
4. 任务项列表、新增和编辑合并为一个任务项管理页面：左侧卡片列表，右侧复用同一个新增/编辑表单。
5. 任务类型通过“系统统计、材料审核、运营评审”字段决定执行流程，不产生不同详情页面。
6. 通用框架只消费 `completed` 和 `resultText` 两个最终结果。
7. 周任务快照独立保存进行中、审核中、已结算等流程状态；任务参数与展示文案随快照冻结。
8. 模块内任务项全部完成则模块达标，身份每周最高奖励为关联模块奖金之和。
9. 主播身份申请审核合并到主播身份成员，通过弹窗完成通过、失效或禁止；身份成员页同时承载身份调整、重置失效、失效结算、删除和周期任务。
10. 周任务审核列表与结果页分离；查看和审核复用结果页，查看模式只读，审核模式可处理主观任务并完成整周结算。
11. 周审核通过后按结算金额生成待领取记录，由主播在 App 主动领取。

## 重新生成

在 PowerShell 中进入本目录并执行：

```powershell
.\generate-prototypes.ps1
.\render-prototypes.ps1
```

只重渲染指定页面：

```powershell
.\render-prototypes.ps1 -Names '13-H5-本周任务','16-H5-上周奖励待领取'
```

`render-prototypes.ps1` 优先使用工作区自带的 SVG 渲染能力快速生成 PNG；仅在该运行时不可用时回退到 Edge，并清理脚本创建的临时配置目录。
