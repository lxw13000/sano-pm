# SANO直播间互动专项

本目录集中管理SANO直播间互动能力相关的产品需求、业务规则、管理端与App方案、流程图示和原始需求确认资料。当前第一阶段以“互动礼物菜单”为落地能力，后续可扩展多人互动、场控协作、互动设备联动和更多直播玩法。

## 当前设计主线

互动礼物菜单采用“平台模板 + 主播个人模板 + 本场直播快照 + 观众个人累计 + 互动任务 + 主播履约反馈”的闭环：

- 平台管理多个默认模板、礼物范围、菜单项数量、平台音效和安全规则。
- 每名主播最多保存一个个人模板，在直播准备界面选择或编辑，审核通过后启用。
- 开播时生成本场快照；开播后不能编辑，只能暂停、恢复、关闭、静音和处理任务。
- 礼物按“同一观众 + 本场直播 + 同一礼物”累计，达到门槛后按倍数生成任务。
- 同批多次触发保留实际任务次数，但合并强提醒并只公开播放一次关联音效。
- 主播每履约一次点击“完成1次”，系统向对应观众反馈；下播未完成任务如实标记，不自动退款。

- `资源/历史需求/`：后续被新方案替代但仍需追溯的历史版本；当前为空。
- `维护规范.md`：本专项后续文档、设计和资源的维护规则。

## 当前有效范围

当前有效基线为需求文档、两张业务流程图和七张页面原型。页面原型覆盖平台音效库、平台模板管理及新增菜单项弹窗、主播模板审核、主播直播准备、主播直播中任务处理及观众互动菜单。需求状态为“需求讨论稿，待需求评审”；接口协议、数据库设计和详细测试用例尚未纳入本专项基线。

发生冲突时，以用户最新明确确认的规则为最高优先级；产品实现以`需求文档/`中的当前有效文档为准。后续本专项相关需求交流和迭代默认在本目录内维护，不再以`outputs/`或临时渲染目录作为工作入口。
