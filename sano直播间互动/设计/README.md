# SANO直播间互动页面原型

## 图示说明

- `原型图/`中的PNG用于需求评审、预览和分享。
- `源文件/`中的SVG是可编辑、可重新生成的页面原型源文件。
- `生成工具/`保存SVG生成及PNG渲染脚本，输出目录与工具目录分离。
- 管理端原型统一为1672×941，App原型统一为941×1672。
- 页面中的主播、观众、直播数量和任务数据均为原型示例，不代表真实线上数据。

## 业务流程图

1. [互动礼物菜单总体业务链路](原型图/01-业务流程-互动礼物菜单总体业务链路.png)：展示管理端、直播准备、本场快照、观众送礼、任务生成、主播履约和观众反馈的完整链路。
2. [配置、审核与直播生命周期](原型图/02-业务流程-配置审核与直播生命周期.png)：展示选择模板、配置审核、开播快照、直播中操作和下播处理。

## 管理端原型

3. [平台音效库](原型图/03-管理端-平台音效库.png)：音效Icon、名称、文件地址、时长、状态及试听维护。
4. [平台模板管理](原型图/04-管理端-平台模板管理.png)：左侧仅展示模板列表及新增模板入口；右侧依次展示模板基础信息和菜单项列表，新增菜单项使用弹窗。
   - [新增菜单项弹窗](原型图/04A-管理端-平台模板-新增菜单项弹窗.png)：展示关联礼物、触发数量、互动名称、平台公开音效、互动说明和启用状态。
5. [主播模板审核](原型图/05-管理端-主播模板审核.png)：左侧仅展示状态筛选和模板列表；右侧先展示当前模板基础信息，再展示菜单项详情、风险命中及审核操作。

## App直播间原型

6. [主播端—直播准备互动礼物菜单](原型图/06-App主播端-直播准备互动礼物菜单.png)：直播准备入口、启用开关、本场菜单预览和开播快照提示。

## 重新生成

在PowerShell中执行：

```powershell
.\设计\生成工具\generate-prototypes.ps1
.\设计\生成工具\render-prototypes.ps1
```

只重渲染指定页面：

```powershell
.\设计\生成工具\render-prototypes.ps1 -Names '07-App主播端-直播中互动任务','08-App观众端-直播间互动菜单'
```

新增或更新图示后，应同步更新需求文档中的引用和本页面列表，并检查图示与正文规则一致性。
