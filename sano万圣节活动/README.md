# SANO 万圣节活动

产品文档：V1.3；原型：V1.2（单场达标修订）。日期：2026-10-26。

主文档按核心规则、时间阶段、必要流程、页面要求、统计口径、开发约束、验收及上线待定项组织；研发以主文档为业务依据，原型说明用于查看和操作演示。

V1.2：每日奖励按当天任意单场达到 1000 分判断，每天一份；H5 展示今日单场最高分，今日领奖与历史补领分开。榜单总积分仍持续累计。共 28 个关键场景。

V1.1：H5 展示后台配置的排名奖励；后台支持商城头像框选择及区域投入汇总，总投入按 `(金币投放 + 南瓜灯投放 × 200) ÷ 10000` 显示美元。

本目录与 `sano提现管理` 同级，沿用其目录组织、管理端视觉、交互源文件与 PNG 同源导出方式。
