# SANO用户评分体系专项

本目录集中管理SANO用户评分体系的产品需求、管理端原型、可编辑源文件、生成工具和原始输入资料。

## 当前范围

用户评分体系由评分类型、评分参数和用户评分结果三部分组成：

- 评分类型由运营人员维护，并关联一个或多个评分参数。
- 评分参数对应一个具体的技术执行实现，由技术人员维护。
- 系统按照既有计算架构定时计算，输出用户在各评分类型下的最终评分及参数明细。
- 本专项只定义管理端配置、查询、权限和交互，不重新定义计算模型、调度、默认分、异常处理或数据库架构。

## 目录结构

- `需求文档/`：当前有效产品需求文档。
- `设计/原型图/`：用于评审和分享的PNG原型。
- `设计/源文件/`：可编辑的SVG原型源文件。
- `设计/生成工具/`：SVG生成与PNG批量导出工具。
- `资源/需求输入/`：用户提供的数据表设计等原始输入。
- `资源/历史需求/`：后续被替代的历史资料。
- `维护规范.md`：本专项的文档与设计维护规则。
