# SANO用户评分体系管理端原型

## 原型说明

- 管理端原型共8张，统一为1672×941。
- `原型图/`保存评审用PNG，`源文件/`保存可编辑SVG。
- `生成工具/`提供SVG批量生成和PNG批量导出能力。
- 页面示例中的类型、参数、用户ID和分数均为演示数据，不代表真实线上数据。
- 原型聚焦管理端配置和查询，不展现评分算法、调度和异常处理的技术实现。

## 重新生成

```powershell
.\sano用户评分\设计\生成工具\generate-prototypes.ps1
.\sano用户评分\设计\生成工具\render-prototypes.ps1
```

只重渲染指定页面：

```powershell
.\sano用户评分\设计\生成工具\render-prototypes.ps1 -Names '01-管理端-评分类型','07-管理端-用户评分结果'
```
