# SANO用户任务体系页面原型

## 原型说明

- 管理端页面：21张，统一为1672×941；主页面、操作状态、抽屉和弹窗按业务层级分别展示。
- App H5页面：14张；常规页面为940×1640，上周奖励与任务模块组合页为可滚动长页。
- `原型图/`中的PNG用于评审和分享，`源文件/`中的SVG作为可编辑源文件保留。
- `生成工具/`保存SVG生成和PNG渲染脚本，输出目录已经与工具目录分离。
- 页面中的主播、周期、任务、结果和奖励均为原型示例数据，不代表真实线上数据。
- 任务项页面展示任务参数JSON、结果定义JSON和统一结果示例；任务执行器不感知奖励。
- 任务模块页面配置模块周期、任务组合、小周期完成数量与连续要求，以及模块奖励策略。
- 数值阶梯表单采用“计奖依据任务 + 计奖指标 + 通用档位”，不与收入、邀请等具体业务绑定。
- H5模块进度按“已完成任务项数/模块任务项总数”展示；天数、条数、次数等属于具体任务进度。
- H5模块列表和模块内任务列表使用公共组件；模块列表只展示模块级概述，任务详情根据任务渲染器独立展示。
- 模块奖励优先突出金币和钻石，存在其他资产时显示“奖励详情”并通过弹窗逐项展示。
- 配置菜单拆分为任务库、任务模块、用户身份三个子菜单，不再使用任务库内的二级页签。
- 任务库采用左右结构，左侧筛选和选择任务项，右侧直接完成任务详情查看、新增、编辑与保存，不再使用任务项抽屉。
- 任务模块主页面保留“基础信息、关联任务、奖励配置”三段完整展示；关系和奖励的实际修改使用抽屉，选择对象和编辑单条明细使用弹窗。
- 任务模块基础信息包含奖励类型；阶梯奖励配置通过任务来源JSON声明来源任务和结果指标路径。

  - 任务模块
  - 用户身份
- 用户身份成员
- 周期任务审核
- 奖励领取记录
- App优质主播模块

  - 本周期任务与材料提交
  - 任务模块详情与任务列表
  - 具体任务结果详情
  - 历史周期奖励与主动领取
  - 上周任务模块列表、模块详情与冻结任务详情
  - 奖励组合与奖励详情弹窗
  - 分享奖励模块、分享任务详情与上传入口
  - 模块未完成与无奖励说明
  - 奖励记录与规则说明

## 重新生成

在PowerShell中执行：

```powershell
.\设计\生成工具\generate-prototypes.ps1
.\设计\生成工具\render-prototypes.ps1
```

只重渲染指定页面：

```powershell
.\设计\生成工具\render-prototypes.ps1 -Names '13-H5-本周任务','16-H5-上周奖励待领取'
```

生成脚本输出SVG到`源文件/`；渲染脚本从`源文件/`读取SVG并输出PNG到`原型图/`。
