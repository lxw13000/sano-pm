# 参考资源

本目录用于保存SANO用户任务体系的原始需求输入和历史参考资料，不作为当前实现规则的唯一依据。

## 需求输入

- [Sano Live优质主播政策脑图](需求输入/Sano_Live_优质主播政策脑图.mm)：用户提供的FreeMind格式政策脑图，用于梳理身份、任务与奖励方向。

## 历史需求

- [7月优质主播功能设计文档](历史需求/7.优质主播功能设计文档.md)：本次体系化升级前的优质主播功能设计，用于对照原有直播任务和奖励流程。

## 归档规则

- 用户提供的脑图、截图、政策文件和原始说明放入`需求输入/`。
- 已被新方案替代但仍需追溯的需求文档放入`历史需求/`。
- 当前有效产品需求统一放在`../需求文档/`，最终原型放在`../设计/原型图/`。
- 资源中的内容用于提供背景，实际产品规则以当前需求文档和用户最新确认内容为准。
- 设计生成脚本不得放入资源目录，统一归档到`../设计/生成工具/`。
