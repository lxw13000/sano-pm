# SANO用户画像专项

本目录集中管理SANO用户详情画像相关的需求、设计文件和生成资源，作为专项用户分析资料使用。

## 目录结构

- `需求文档/`：产品需求、指标口径和逐页开发说明。
- `设计/原型图/`：用于评审和分享的PNG页面原型。
- `设计/源文件/`：可编辑、可重新生成的SVG原型源文件。
- `设计/生成工具/`：与原型设计配套的SVG生成及PNG导出脚本。
- `资源/`：用户提供或其他来源的参考图片、文档、案例及辅助素材，不存放生成工具。

## 主要入口

- [用户详情画像需求文档](需求文档/用户详情画像.md)
- [页面原型说明](设计/README.md)

## 重新生成原型

1. 运行 `设计/生成工具/generate-prototypes.ps1`，输出SVG到 `设计/源文件/`。
2. 运行 `设计/生成工具/render-prototypes.ps1`，输出PNG到 `设计/原型图/`。
