# 提现管理交互关系

当前版本：V1.4 · 提交二次确认。

## 页面层级

| 层级 | 入口 | 承载 | 返回 |
| --- | --- | --- | --- |
| 提现管理 | 资金管理 → 提现管理 | 主列表，全部字段直接展示 | 保留查询、分页及滚动位置 |
| 初审 | 待审核行操作或主列表批量选择 | 右侧抽屉，固定本批 | 手动关闭回列表 |
| 复审 | 打款失败行操作或主列表同方式批量选择 | 右侧抽屉，固定本批 | 手动关闭回列表 |
| 下一批复审 | 原批“复审失败订单 N 笔” | 同一抽屉切换固定失败子批次 | 返回原批完整结果 |
| 重新处理未受理 | 原批“重新处理未受理订单 N 笔” | 同一抽屉切换未受理子批次 | 返回原批完整结果 |
| 订单详情 | 列表或抽屉的订单号／详情 | 左右分栏居中弹窗 | 关闭回实际来源 |

## 主列表选单

全部字段直接展示，宽表内部横向滚动，固定订单及操作列。仅主列表提供勾选、取消选择与当前页全选；初审可跨提现方式，复审必须同一方式，提前限制不兼容勾选。翻页、修改查询或每页条数清除选择。

## 固定批次抽屉

从主列表确定订单后，抽屉完整保留该批。不提供状态筛选、二次复选框、勾选当前视图、取消勾选或隐藏已选项。参数统一作用于本批；需要自定义订单范围时，在主列表确定。

布局为本批笔数／金额／方式、提交后的单一结果摘要、本批订单列表、本次处理。提交初审／复审按钮在本次处理块左侧，底部右侧仅关闭。

## 本次处理的展开与提示

“展开处理参数／收起处理参数”在本次处理标题旁。收起只隐藏内容，标题、开关和“先核对上方订单，再填写并提交本次处理”始终保留。核单提示红色加粗，不在结果区放参数开关。

提交前参数可编辑，提交后参数只读并收起，展开用于查看该次记录。不能通过展开参数再次执行原批提交。

## 提交二次确认

初审、复审、退款及下一固定子批次均为：填写参数 → 点击提交 → 必填校验 → 确认弹窗 → 确认提交后执行。弹窗显示处理结果、本批笔数和 USD 金额、提现方式；按场景补充渠道、是否换号、退款理由及内部备注。

“返回修改”或 Escape 不执行处理，保留抽屉和参数，默认焦点在返回修改。弹窗打开时抽屉不可操作，Tab 在确认弹窗内循环。确认前重新校验当前订单及参数快照和渠道；变化时返回核对。提交中禁重复点击和返回，完成后仅关闭确认弹窗。

## 提交与结果

提交后抽屉不关闭，表格逐笔更新实际状态。仅一条动态摘要，例如“本批已结束 2 / 3 笔 · 打款失败 1 笔”，全部完成后为“本批已结束 3 / 3 笔 · 全部已结束”。不再另放提交轮次消息或重复进度框。

失败订单按方式形成下一批复审；未受理订单单独形成下一批重新处理。两种入口均不会自动提交，也不会再次处理原批中成功或打款中的订单。原批可随时返回查看。

初审不通过退款完成为驳回已退款；失败复审退款完成为已退款。退款理由用户可见，内部备注独立。复审仅提交是／否，换号由后台逐笔处理。

## 刷新与关闭

每 30 秒自动刷新，支持手动刷新，显示最近刷新时间。刷新不移除本批、不清空提交前草稿、不改变滚动位置。提交前状态变化不悄悄缩小范围，应提示回列表重新确定订单。

关闭不取消已受理任务；最近处理批次可回看。关闭结束轮询，重新打开不叠加定时器。提交期间禁重复提交及参数修改，点击遮罩不关闭。

## 详情与键盘

左详情右时间轴同时可见，无页签，独立滚动；保留历史换号及每次打款链。时间轴顶部展示最新进展和定位入口。关闭详情返回原抽屉或列表。

浮层内 Tab 循环，Escape 优先关闭最上层确认弹窗（提交中不可关闭），其次详情，最后抽屉。状态文字与颜色并用，金额与币种同时显示，完整编号可复制。
