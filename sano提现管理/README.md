原型仅使用虚构示例数据，在浏览器内模拟提交和打款结果，不连接真实支付、退款或后台接口。刷新页面恢复初始数据。金额、渠道和失败结果用于演示，不能作为线上配置或业务数据。

设计沿用参考专项的深蓝导航、紫色主操作、浅色卡片和目录组织；本专项以可交互 HTML/CSS/JS 为可编辑源文件，PNG 用于评审。

当前为 V1.4 提交二次确认版，含 25 个场景；原版保留在设计归档中。重点完善前置选单限制、结果优先、初审就地转复审、批次回看、退款理由预览及时间轴定位。

V1.2：初审、复审均为订单列表在上、本次处理在下；提交位于本次处理块内，底部仅保留关闭。

V1.3：主列表全部字段直接展示；抽屉不再二次筛选勾选。参数开关归属本次处理，核单提示红色加粗，提交后仅一条结果摘要。

V1.4：初审、复审及退款提交均弹二次确认；返回修改保留草稿，确认提交才执行，处理完成抽屉仍保持打开。
