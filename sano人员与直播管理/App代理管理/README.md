核心口径已于2026-10-26确认：总收入沿用现有口径；自定义单个完整自然周；当前有效直属名单选人，统计所选周个人数据。本目录独立维护App页面。

源文件为HTML、CSS、JavaScript，结构参考同级万圣节活动原型。浏览器直接打开即可交互，无需启动服务；没有SVG页面或远程依赖，PNG由同一HTML通过浏览器截图生成。

主播列表为真实表格：一位主播一行，八项字段独立成列，固定ID、昵称，默认查看时长及两项天数，横向滚动查看三项收入。支持周切换、日历翻月、选周确认和取消、返回、刷新、失败重试及分批加载，共20个演示场景。

样例数据均为虚构。时间固定为2026-10-26 18:00 SANO Time，美元单位仅作示意，上线沿用App现有单位。顶部演示工具栏不属于正式产品界面。

维护源文件：设计/源文件/index.html、styles.css、app.js。重新验证运行 node 设计/生成工具/validate-prototypes.js，重新导出运行 node 设计/生成工具/generate.js。

工具使用本机Codex运行时Playwright和Chrome，可通过SANO_NODE_MODULES、SANO_CHROME指定依赖及浏览器路径。使用交互原型本身不需要这些工具。
