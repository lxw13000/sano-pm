本目录位于“需求设计”目录下，独立维护需求。当前包含Markdown需求文档、25张页面与状态的PNG评审图、可编辑SVG源文件和生成工具。未实现真实业务程序或数据库。

当前两级菜单：组织管理（BD列表、代理列表、主播列表）；直播与收入（主播收入、代理收入、主播工作、直播审核）。BD与代理仅提供查询及查看，不含新增、编辑。

主播详情包含基础资料、账号与账户、最近一次上报及同设备查询；金币、钻石与美元收入分别标注单位。详细资料同页滚动，设备记录使用右侧抽屉。
