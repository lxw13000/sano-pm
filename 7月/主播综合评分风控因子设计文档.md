## 1. 背景与目标

### 1.1 项目背景

平台当前已具备涉黄、挂播、直播对比（是否为同一个人）等风控能力，并已形成对应的识别、命中、复核、处罚流程。随着“主播综合评分评估系统”逐步稳定，综合评分可以作为主播质量、稳定性、可信度的辅助参考，用于调节疑似类、累计类风控策略的触发阈值。

本设计不重做现有风控系统，也不改变现有风控识别能力，而是在现有风控策略基础上新增“综合评分风控因子”。评分高的主播不是免罚，而是在疑似类、累计类风控中获得更合理的容错；严重违规、强命中违规是否继续执行原有风控流程需支持配置，默认建议执行原流程。

### 1.2 核心目标

+ **辅助风控**：综合评分作为风控阈值调节因子，服务于现有涉黄、挂播、直播对比等策略。
+ **差异化阈值**：不同综合评分等级可配置不同疑似命中次数、统计周期、复核方式和处置动作。
+ **强命中可配置**：严重违规、强命中违规默认建议走原风控流程，但需支持配置是否继续原流程、是否仅记录、是否进入人工复核。
+ **配置化扩展**：支持后续新增风控类型、评分等级、阈值、动作、灰度范围等配置。
+ **可追溯**：每次风控因子生效时需记录当时的综合评分、评分等级、命中配置和最终动作，便于运营追溯。

### 1.3 设计参考思路

+ 主流直播平台普遍采用“规则 + 自动识别 + 人工复核 + 分级处置”的治理模式。
+ 对实时直播场景，平台通常需要区分强违规与疑似违规，避免仅凭低置信度模型结果直接处罚。
+ 对主播侧治理，成熟平台更重视历史表现、账号信誉、违规上下文、直播场景等多因子综合判断。
+ 本方案借鉴上述思路，将主播综合评分作为“账号质量/可信度”因子，用于疑似类、累计类风控阈值调节。

## 2. 功能设计

### 2.1 管理端功能设计

#### 2.1.1 综合评分风控因子模块

+ **功能描述**：在管理端新增“综合评分风控因子”功能模块，用于配置综合评分在风控策略中的使用规则。
+ **模块入口**：可挂在“主播综合评估”模块下，也可挂在“风控管理”模块下，具体由管理端菜单规划确定。
+ **子功能块**：
    - **风控因子策略配置**：配置风控类型、适用命中类型、评分等级、阈值和动作。
    - **评分等级配置**：按等级最低分配置综合评分分层，如S/A/B/C/D或自定义等级。
    - **因子生效记录**：查看综合评分因子参与风控判断的记录。
    - **策略灰度配置**：配置国家、主播范围、风控类型的灰度生效范围。
+ **基础能力**：
    - 支持按风控类型、评分等级、启用状态、国家、创建时间筛选。
    - 支持新增、编辑、启用、停用策略。
    - 所有配置变更需记录操作人、操作时间、变更前后值及操作原因。

#### 2.1.2 风控因子策略配置

+ **功能描述**：针对不同风控类型配置综合评分如何影响疑似类、累计类风控阈值。
+ **配置项**：
    - **风控类型**：涉黄、挂播、直播对比等。
    - **命中类型**：强命中、疑似命中、累计命中。
    - **评分等级**：如S、A、B、C、D、未评分。
    - **统计周期**：近1小时、近24小时、近7天、自然日、自然周等。
    - **命中次数阈值**：达到指定次数后触发对应动作。
    - **模型置信度阈值**：用于疑似命中场景，可按评分等级调节。
    - **处置动作**：提醒、人工复核、限流、断播、进入原封禁流程、仅记录等。
    - **是否继续原流程**：命中该策略后是否继续执行原有风控流程。
    - **复核优先级**：高、中、低。
    - **是否启用**：策略开关。
    - **灰度范围**：国家、主播ID白名单、主播等级、时间范围。
+ **数据约束**：
    - 同一风控类型、命中类型、评分等级、统计周期下，仅允许一条有效配置。
    - 强命中策略需支持配置是否继续原流程，默认值为继续原流程。
    - 未评分主播需有独立等级配置；默认不应比普通评分主播更宽松。

#### 2.1.3 评分等级配置

+ **功能描述**：配置综合评分对应的风控分层，供不同风控类型复用。评分等级仅维护等级最低分，系统按最低分从高到低自动形成等级区间，避免人工配置最高分/最低分不连续导致真空期。
+ **默认分层**：

| 等级 | 等级最低分 | 自动形成区间 | 风控含义 |
| :--- | ---: | :--- | :--- |
| S级 | 90 | 90-100 | 高质量/高可信主播 |
| A级 | 80 | 80-89.99 | 较高质量主播 |
| B级 | 70 | 70-79.99 | 普通偏优主播 |
| C级 | 60 | 60-69.99 | 普通主播 |
| D级 | 0 | 0-59.99 | 低质量或需重点观察主播 |
| N级 | - | 未评分 | 无评分数据，按保守策略处理 |

+ **配置规则**：
    - 每个评分等级仅配置等级最低分，不配置最高分。
    - 系统按最低分倒序计算等级区间：当前等级最低分至上一等级最低分以下。
    - 最低等级必须配置为0分，确保0-100分无真空期。
    - 未评分主播必须单独配置等级。
    - 未评分主播必须单独配置策略。
    - 分层名称可调整，但不影响历史记录展示。

#### 2.1.4 因子生效记录

+ **功能描述**：记录每次综合评分因子参与风控判断的结果。
+ **列表字段**：
    - 记录ID
    - 主播ID
    - 直播间ID
    - 风控类型
    - 命中类型
    - 风控命中时间
    - 当前生效综合评分
    - 评分等级
    - 命中次数
    - 统计周期
    - 命中的因子配置
    - 原风控动作
    - 因子调整后动作
    - 是否进入原流程
    - 创建时间
+ **查询条件**：主播ID、直播间ID、风控类型、评分等级、动作、时间范围。

#### 2.1.5 策略灰度配置

+ **功能描述**：支持综合评分风控因子分阶段上线，降低误伤和策略波动风险。
+ **灰度维度**：
    - 国家/地区
    - 主播ID白名单
    - 主播评分等级
    - 风控类型
    - 时间范围
+ **灰度阶段**：
    - **观察期**：只记录因子建议动作，不影响实际风控动作。
    - **小流量生效**：仅对指定主播或国家生效。
    - **全量生效**：策略稳定后扩大到全部适用范围。

## 3. 核心业务规则梳理

### 3.1 总体原则

+ **不替代原风控**：涉黄、挂播、直播对比的识别逻辑、原始命中逻辑、强处罚流程保持不变。
+ **只做辅助因子**：综合评分只影响疑似类、累计类、阈值类策略。
+ **强命中可配置**：严重违规、强命中违规默认建议执行原风控流程，但实际是否继续原流程、仅记录或转人工复核需由风控因子策略配置决定。
+ **评分高不免罚**：高评分主播仅在疑似/累计命中场景中获得更高容错，不享有豁免。
+ **记录快照**：风控判断时需保存当时的综合评分和评分等级，后续评分变化不影响历史记录。
+ **配置不回溯**：策略配置变更只影响后续新产生的风控判断，不回溯历史判断。

### 3.2 风控类型适用范围

| 风控类型 | 现有能力 | 综合评分适用方式 |
| :--- | :--- | :--- |
| 涉黄风控 | 已有识别与处罚流程 | 调节疑似涉黄累计次数阈值；强涉黄是否继续原流程可配置 |
| 挂播检测 | 已有识别与处罚流程 | 调节疑似挂播累计次数、复核优先级；明确挂播是否继续原流程可配置 |
| 直播对比 | 已有是否同一人检测能力 | 调节疑似非本人复核阈值；高置信非本人是否继续原流程可配置 |

### 3.3 评分读取规则

+ **读取字段**：读取主播综合评分评估系统中的当前生效综合评分。
+ **锁定评分**：如主播评分被运营锁定，则按锁定后的当前生效综合评分参与风控因子判断。
+ **无评分主播**：进入“未评分”区间，按保守策略处理。
+ **读取失败**：如评分服务异常，默认不放宽风控阈值，按原风控流程执行，并记录异常原因。

### 3.4 涉黄风控因子规则

+ **适用范围**：仅适用于疑似涉黄、累计涉黄命中场景。
+ **强命中处理**：明确涉黄、强命中涉黄、人工确认涉黄默认建议执行原封禁流程，但需支持通过策略配置控制是否继续原流程、仅记录或进入人工复核。
+ **示例配置**：

| 评分等级/自动区间 | 统计周期 | 疑似涉黄累计次数 | 处置动作 |
| :--- | :--- | ---: | :--- |
| 90-100 | 近7天 | 7次 | 进入原封禁流程 |
| 80-89 | 近7天 | 6次 | 进入原封禁流程 |
| 70-79 | 近7天 | 5次 | 进入原封禁流程 |
| 60-69 | 近7天 | 4次 | 进入原封禁流程 |
| 0-59 | 近7天 | 3次 | 进入原封禁流程 |
| 未评分 | 近7天 | 3次 | 进入原封禁流程 |

+ **规则说明**：
    - 评分越高，疑似涉黄累计容错次数可适当提高。
    - 一旦命中强涉黄或人工确认涉黄，默认建议执行原封禁流程，实际动作以策略配置为准。
    - 因子只改变“达到多少次后进入原流程”，不改变原流程本身。

### 3.5 挂播检测因子规则

+ **适用范围**：疑似挂播、累计挂播、低置信挂播场景。
+ **强命中处理**：明确挂播、长时间无人、黑屏/静态画面等强命中场景默认建议执行原挂播流程，但需支持通过策略配置控制是否继续原流程、仅记录或进入人工复核。
+ **示例配置**：

| 评分等级/自动区间 | 统计周期 | 疑似挂播累计次数 | 处置动作 |
| :--- | :--- | ---: | :--- |
| 90-100 | 近7天 | 8次 | 人工复核 |
| 80-89 | 近7天 | 6次 | 人工复核 |
| 70-79 | 近7天 | 5次 | 原挂播流程 |
| 60-69 | 近7天 | 4次 | 原挂播流程 |
| 0-59 | 近7天 | 3次 | 原挂播流程 |
| 未评分 | 近7天 | 3次 | 原挂播流程 |

+ **规则说明**：
    - 高评分主播在疑似挂播场景中可优先进入人工复核，降低误伤。
    - 明确挂播默认建议执行原有挂播流程，实际动作以策略配置为准。
    - 对低评分或未评分主播保持更保守的阈值。

### 3.6 直播对比因子规则

+ **适用范围**：疑似非本人、低置信非同一人、短时间画面异常等场景。
+ **强命中处理**：高置信非本人、人工确认非本人、身份绕过等强违规场景默认建议进入原直播对比流程，但需支持通过策略配置控制是否继续原流程、仅记录或进入人工复核。
+ **示例配置**：

| 评分等级/自动区间 | 统计周期 | 疑似非本人累计次数 | 处置动作 |
| :--- | :--- | ---: | :--- |
| 90-100 | 近7天 | 3次 | 人工复核 |
| 80-89 | 近7天 | 2次 | 人工复核 |
| 70-79 | 近7天 | 2次 | 原直播对比流程 |
| 60-69 | 近7天 | 1次 | 原直播对比流程 |
| 0-59 | 近7天 | 1次 | 原直播对比流程 |
| 未评分 | 近7天 | 1次 | 原直播对比流程 |

+ **规则说明**：
    - 直播对比涉及身份真实性，高评分只能影响疑似场景的复核路径。
    - 高置信非本人不能仅因评分高自动放宽，实际动作需以强命中策略配置为准。
    - 对高评分主播更适合走人工复核，避免模型误判导致误伤。

### 3.7 动作合并规则

+ **多策略同时命中**：按最严格动作执行。
+ **强命中 + 疑似命中同时存在**：强命中策略优先生效，是否继续原流程以强命中配置为准。
+ **多个评分等级配置异常命中**：按未评分或最低评分等级策略处理。
+ **因子服务异常**：按原风控策略执行，不因异常放宽。

## 4. 设计角色与环境配置

### 4.1 角色权限

+ **运营**：配置评分等级、风控因子策略、灰度范围，查看因子生效记录。
+ **风控审核人员**：查看综合评分因子对风控结果的影响，进行人工复核。
+ **系统**：读取主播综合评分，匹配风控因子配置，输出最终动作建议或执行动作。
+ **主播**：无直接配置权限，受现有风控和综合评分因子共同影响。

### 4.2 环境配置

+ **评分服务**：提供主播当前生效综合评分查询能力。
+ **风控服务**：在现有涉黄、挂播、直播对比命中后，调用综合评分风控因子模块。
+ **配置服务**：提供评分等级、风控因子策略、灰度配置读取能力。
+ **日志服务**：记录因子生效快照、策略命中结果、最终动作。
+ **时间口径**：统计周期和记录时间统一采用UTC+8。

## 6. 测试场景推演与预期数据

### 6.1 高评分疑似涉黄容错

+ **场景**：主播A综合评分85分，近7天疑似涉黄累计6次。
+ **预期**：命中80-89区间配置，进入原封禁流程。

### 6.2 高评分未达涉黄阈值

+ **场景**：主播A综合评分85分，近7天疑似涉黄累计5次。
+ **预期**：未达到80-89区间6次阈值，不进入原封禁流程，仅记录风控命中。

### 6.3 强涉黄策略配置生效

+ **场景**：主播A综合评分95分，命中强涉黄，强命中策略配置为继续原流程。
