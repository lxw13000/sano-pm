# SANO优质主播必修课

## 直播规范与违规管理指南

> 文档状态：规则讨论稿，确认后面向SANO优质主播发布。

成为SANO优质主播不仅是一份荣誉，更是一份责任。本指南将帮助你了解优质主播的专属权益、直播要求、周期考核和违规处理规则。

本指南适用于优质主播的单人直播、多人直播、连麦和派对房等场景。

---

## 一、资格申请、生效与考核周期

### 1. 申请条件

- 申请人所在国家或地区必须属于平台后台已开放的范围。
- 每个开放国家或地区由后台配置对应的高峰时段。
- 高峰时段以该国家首都所在地时区的每日20:00—24:00为基准，再换算为UTC+8时间供平台统一结算。
- 示例配置：国家/地区`LA`的高峰时段配置为UTC+8的19:00—23:00，对应当地首都时间20:00—24:00。主播应以平台针对其国家或地区实际展示的时间为准。
- 每个资格周期内，主播每天须在高峰时段完成不少于120分钟的有效直播，每周至少达到6个有效直播日。
- 一个有效直播日，是指主播在当天对应的高峰时段内完成不少于120分钟的有效直播。
- 只有符合本指南质量要求的直播时长才属于有效直播时长；黑屏、静音、挂机等低质量直播不能用于完成120分钟要求。

### 2. 有效周期

- 优质主播资格和奖励按周结算。
- 每个周期为UTC+8时区的周一00:00至周日24:00。
- 高峰时段、有效直播时长和有效直播天数均按该周期统计。

### 3. 奖励结算与发放

- 当前周期结束后，平台在下一个周期的第1至第2个自然日内进行综合核算并完成奖励发放。
- 结算和发放时间统一按UTC+8时区计算。
- 例如：某个结算周期为1日至7日，平台将在8日至9日内完成该周期奖励的核算与发放。
- 如主播在当前周期内达到取消奖励条件，该周期奖励不予发放；进入下一周期后恢复正常奖励资格，并重新按下一周期表现核算。

### 4. 审核与生效

- 资格审核持续进行，不限制只能在固定日期申请或审核。
- 审核通过后，资格从审核周期的下一个周一开始生效，确保每个生效周期都是完整的一周。
- 例如：主播在周二审核通过，资格从下周一开始生效。
- 申请期主播被巡查发现违规时，平台会保留记录并在资格审核时综合考虑，但该记录不计入尚未开始的正式资格周期警告次数。

## 二、优质主播的基本责任

优质主播应对自己的形象、直播内容、互动质量和直播环境负责。

### 1. 保持良好的个人形象

- 直播期间必须化妆，保持整洁、得体的个人形象。
- 主播本人应正常出镜，服装、发型、仪态和直播背景不能明显影响观看体验。
- 高峰时段的综合表现应与申请时上传的视频保持一致。平台将结合主播本人、形象状态、内容质量、互动状态和才艺表现等维度综合判断，不以单一项目决定。

### 2. 持续提供有效直播内容

- 开播前应准备聊天、表演、讲解或其他明确的直播内容。
- 开播后应持续进行内容展示，不能只维持开播状态或等待用户进入。
- 主播应保持声音正常、画面清晰稳定，并处于适合直播的状态。

### 3. 积极与用户互动

- 主动向进入直播间的用户打招呼。
- 收到礼物后应进行有效回应，包括口头感谢或点名感谢。
- 直播过程中应关注用户和直播内容，不能长时间看手机或处理与直播无关的事情。

### 4. 遵守平台直播要求

- 在SANO直播期间，不得同时在其他平台直播。
- 不得使用黑屏、静音、挂机、躺播等方式凑直播时长。
- 网络、设备或环境出现问题时，应尽快修复；无法恢复正常时应结束直播，不能持续进行低质量直播。

## 三、开播前应该做好什么

每次开播前，请确认：

- [ ] 已化妆并整理好服装、发型和直播背景。
- [ ] 摄像头画面清晰、稳定、无遮挡。
- [ ] 麦克风声音正常，没有持续静音或异常噪声。
- [ ] 网络连接稳定。
- [ ] 已准备本场直播的主要内容。
- [ ] 本人能够持续出镜并参与直播。
- [ ] 没有在其他平台同时直播。

如果设备、网络或个人状态无法保证正常直播，请先解决问题再开播。

---

## 四、直播中应该怎么做

### 正确的直播状态

- 主播本人持续正常出镜。
- 保持聊天、表演、讲解或其他有效内容输出。
- 及时欢迎进入房间的用户。
- 对礼物进行口头感谢或点名感谢。
- 面向直播用户参与内容，不长时间做无关事情。
- 保证声音可以正常收听，画面可以正常观看。

### 遇到异常时

- **没有声音：**立即检查麦克风、系统权限和静音状态。
- **画面黑屏、模糊、抖动或被遮挡：**立即调整摄像头、网络、支架或光线。
- **需要暂时离开：**尽快返回；离开镜头持续达到2分钟会触发平台检测，预计无法及时返回时应结束直播。
- **网络或设备无法恢复：**结束本场直播，修复后重新开播。
- **多人直播中的嘉宾异常：**房主应及时提醒、切换展示或将嘉宾移出麦位。

## 五、哪些行为属于违规

以下行为会影响用户观看体验，经平台审核确认后，将记为有效违规。

| 规则编号 | 违规行为 | 判断依据 | 正确做法 |
| --- | --- | --- | --- |
| V-01 | 长时间坐着不说话 | 主播持续出镜，但长时间没有语言、表演、内容展示或用户互动 | 持续输出内容并与用户互动；不具备直播状态时结束直播 |
| V-02 | 静音直播 | 直播间持续没有有效声音，用户无法正常收听 | 检查麦克风和静音状态，恢复正常声音 |
| V-03 | 躺床直播或躺播 | 主播以躺卧状态进行低参与、低质量直播 | 保持适合直播的姿态和参与状态 |
| V-04 | 长时间离开镜头 | 主播离开有效画面持续达到2分钟时触发检测，并进入综合审核 | 保持正常出镜；不能及时返回时结束直播 |
| V-05 | 黑屏直播 | 画面持续黑屏或没有可识别内容 | 修复画面；无法修复时结束直播 |
| V-06 | 长时间空等用户 | 以等待用户进入为由，不进行内容展示或互动 | 无论当前人数多少，都应持续提供直播内容 |
| V-07 | 仅播放音乐 | 只播放音乐，主播没有演唱、讲解或其他实际参与 | 主播本人应参与表演、讲解或互动 |
| V-08 | 长时间看手机 | 持续观看或操作其他设备，没有面向直播用户提供内容 | 将注意力放在直播内容和用户互动上 |
| V-09 | 画面长期异常 | 画面长期模糊、黑屏、严重抖动或被遮挡，影响正常观看 | 调整网络、摄像头、支架、光线或遮挡物 |
| V-10 | 挂播或其他低质量直播 | 仅维持开播状态，没有真实、持续的内容或互动 | 保持真人参与和有效内容输出 |
| V-11 | 同时在多个平台直播 | SANO直播期间，同时在其他平台进行直播 | 同一时间只在SANO进行直播 |
| V-12 | 高峰时段综合表现明显不符 | 平台结合主播本人、形象、内容、互动和才艺等综合表现，与申请视频进行比对 | 保持与申请审核时相符的综合直播表现 |

### 补充说明

- 直播中可以播放音乐，但主播必须真实参与演唱、表演、讲解或互动；仅播放音乐且主播不参与才属于违规。
- 除“离开镜头达到2分钟触发检测”外，不用同一个固定时长判断所有行为。看手机、沉默、等待用户和画面异常等行为由持续时间、当前内容、互动状态和影响程度综合判断；20秒以上可作为检测参考，但不等于达到20秒就自动处罚。
- 短暂喝水、调整设备或处理突发问题，不会只凭一个画面直接判定为违规。平台应查看连续直播片段并结合主播是否及时恢复正常进行判断。
- 同一连续行为即使同时出现黑屏、无声、离镜等多个问题，原则上作为一个违规事件处理，不重复累计警告。
- 主播恢复正常直播后再次发生新的、相互独立的违规行为，可以作为新的违规事件审核。

## 六、多人直播应该怎么做

多人直播中，房主负责主要内容和麦位管理，嘉宾对自己的出镜和互动质量负责。

### 1. 房主责任

房主必须做到：

- 持续主持、表演或组织互动，保证房间有明确的主要直播内容。
- 关注麦上嘉宾的声音、画面和互动状态。
- 嘉宾离开画面或关闭摄像头超过30秒，或者持续不说话、不互动时，及时提醒或调整。
- 嘉宾长期低活跃，或者出现躺播、睡播等行为时，将其移出麦位。
- 嘉宾出现黑屏、静音、躺播、挂机等低质量行为时，及时提醒、调整展示或移出麦位。

麦上有多名嘉宾时，建议房主主动放大或突出正在有效互动的嘉宾麦位，以保证用户能够看到主要内容。该操作不是强制要求，未操作时不能单独认定为违规。

如果房主已经及时提醒、切换展示或移出异常嘉宾，不应仅因嘉宾的短暂异常直接判定房主违规。

### 2. 嘉宾责任

嘉宾上麦后必须做到：

- 正常出镜，保证声音和画面可用。
- 进行真实的语言、表演或其他有效互动。
- 配合房主安排的直播内容和麦位管理。
- 不长期占用麦位却不说话、不出镜或不互动。
- 不出现本指南第五章所列的低质量直播行为。

### 3. 多人直播责任怎么判断

| 场景 | 责任认定 |
| --- | --- |
| 嘉宾本人黑屏、静音、挂机或长期不互动 | 嘉宾对自身行为负责 |
| 嘉宾离开画面或关闭摄像头超过30秒，房主仍不提醒、不调整、不移麦 | 房主未履行麦位管理责任 |
| 嘉宾躺播、睡播或长期低活跃，房主仍不处理 | 房主未履行麦位管理责任 |
| 多名嘉宾在麦，房主未突出有效互动嘉宾 | 属于直播优化建议，不单独认定为违规 |
| 房主本人不主持、不表演，也不组织主要内容 | 房主未履行主要内容责任 |
| 嘉宾短暂掉线或设备异常，房主立即处理 | 原则上不认定房主违规 |

## 七、违规后怎么处理

### 1. 先提醒整改，再累计有效警告

- 系统或运营发现轻微问题时，可以先向主播发送整改提醒。
- 主播收到提醒后立即改正并恢复正常直播的，本次不计为有效警告。
- 首次出现的轻微问题原则上只提醒、不计次。
- 主播未及时整改、整改后频繁再次发生，或者违规行为经证据审核成立时，才计入有效警告。
- “提醒”用于帮助主播及时纠正问题；“有效警告”才进入本周期的三级处理累计。

### 2. 三级处理规则

平台对审核成立并计次的违规采用三级累计处理：

| 有效警告次数 | 处理结果 | 对主播的影响 |
| --- | --- | --- |
| 第1次 | 警告一次 | 主播收到违规通知，应立即整改 |
| 第2次 | 取消本周期奖励 | 取消本周结算周期内的优质主播奖励；进入下一个周期后恢复正常奖励资格 |
| 第3次 | 取消优质主播资格 | 根据违规行为和历史记录，处理为普通取消或永久取消 |

### 3. 警告累计与清零

- 有效警告按当前优质主播周周期累计，即UTC+8时区的周一至周日。
- 进入下一个周周期后，本周期警告次数自动清零，重新开始累计。
- 警告次数清零不等于删除历史记录。历史违规行为、发生次数、证据和处罚结果继续保留。
- 主播和平台均可查看生效的违规次数及对应记录，作为处罚和后续资格审核的依据。
- 主播曾被取消资格的，再次申请时审核要求会更严格，平台会结合违规类型、严重程度和历史次数综合判断。

### 4. 资格取消与重新申请

- **普通取消：**主播在资格取消满7天后可以再次申请。
- **永久取消：**主播无法再次申请优质主播资格。
- 再次申请不代表自动通过。平台将结合历史违规类型、严重程度、违规次数和整改情况综合审核。
- 哪些情况适用永久取消，由严重违规规则和平台其他安全、内容或行为规范确定。

### 5. 什么情况下才计为有效警告

一次有效警告必须同时满足：

1. 能够说明是哪一场直播、什么时间发生的问题；
2. 有连续直播片段、截图、音轨或平台操作记录等证据；
3. 平台按照本指南完成审核并确认违规成立；
4. 同一连续行为没有被重复计次。

系统提示、用户举报或运营巡查属于问题线索，平台需要结合记录证据审核确认后才能计为有效警告。

### 6. 同一场直播出现多个问题

- 短时间内连续出现多个相关违规行为时，可以记录多个违规标签，但原则上合并为一次有效警告。
- 主播整改并恢复正常后，又发生新的独立违规，可以重新审核并另行计次。
- 同一场长时间直播中频繁发生违规，例如直播3小时内每隔几分钟再次违规，可以根据每次行为的发生时间、间隔和证据记录为多次有效警告。
- 具体生效次数及对应证据应形成平台记录，主播和平台均可查看，避免重复计次和处罚争议。
- 同一事件被系统、运营或多个用户重复上报时，应合并处理，不得重复处罚。

### 7. 规则外的严重违规

本指南主要处理直播质量问题。如主播发生平台其他规则认定的严重违规，平台可以依据相应规则直接取消奖励、取消资格或永久取消资格，不受本指南三级累计处理限制。处罚时应向主播说明所依据的具体规则和证据。

## 八、主播会收到什么通知

平台警告、取消奖励或取消资格时，应向主播说明：

- 违规直播场次和发生时间；
- 违反的规则编号；
- 具体行为和主要证据；
- 当前是第几次有效警告；
- 当前警告所属的周结算周期；
- 本次处理结果和生效时间；
- 应如何整改；
- 与本次判定对应的沟通或复核方式。

主播收到通知后，应查看具体违规行为并及时整改。对判定有异议时，由运营与主播根据违规记录和证据进行沟通并完成复核，双方确认的处理结论应保留记录。

复核认定违规不成立的，平台应撤销本次警告，并恢复由本次警告造成的奖励或资格影响。

## 九、主播每日自检

### 开播前

- [ ] 今天的妆容、服装和形象符合优质主播要求。
- [ ] 画面清晰稳定，声音正常。
- [ ] 已准备好直播内容。
- [ ] 没有在其他平台同时直播。
- [ ] 已确认所在国家或地区当天对应的高峰时段。

### 直播中

- [ ] 我本人持续正常出镜并参与直播。
- [ ] 我没有长时间沉默、离镜、看手机或等待用户。
- [ ] 我主动欢迎新用户，并及时感谢礼物。
- [ ] 画面和声音没有持续异常。
- [ ] 如果是多人直播，我正在履行房主或嘉宾责任。

### 下播前

- [ ] 设备或网络异常时，我没有继续黑屏、静音或挂机直播。
- [ ] 多人房中的低活跃或低质量嘉宾已经及时处理。
- [ ] 本场直播内容、互动和画面质量符合优质主播要求。
- [ ] 今天在高峰时段内已完成不少于120分钟的有效直播，并确认本周有效直播日进度。

## 十、正式发布前需要明确的规则

为保证所有主播和运营执行同一标准，正式发布前还需要补充以下内容：

1. 同一天高峰时段内分多场开播时，是否合并累计达到120分钟。
2. 看手机、沉默、等待用户和画面异常等综合行为的检测信号及主播端提示方式；20秒以上目前只作为参考，不是统一处罚线。
3. 普通取消与永久取消的具体适用条件，以及对应的平台严重违规规则。
4. 运营与主播无法就复核结果达成一致时，由谁作出最终决定以及如何继续处理。

在以上口径确认前，本文件作为规则讨论稿，不作为最终处罚公告。
