# SANO优质主播申请与管理指南

> 文档状态：规则讨论稿，确认后面向SANO主播发布。

成为SANO优质主播不仅是一份荣誉，更是一份责任。本指南将帮助你快速了解优质主播的申请方式、专属权益、直播要求和违规处理规则。

## 30秒看懂优质主播规则

| 你最关心的问题 | 规则 |
| --- | --- |
| 有什么权益？ | 资格生效期间，每周可获得15美元优质主播薪资 |
| 每周要播多久？ | 每周至少6个有效直播日；每天须在高峰时段有效直播至少120分钟 |
| 高峰时段是什么时候？ | 原则上为主播所在国家首都当地时间20:00—24:00，最终以平台针对所在国家或地区展示的时间为准 |
| 怎样才算有效直播？ | 主播本人正常出镜，画面和声音正常，持续提供内容并与用户互动 |

## 一、谁可以申请

符合以下条件的主播可以申请SANO优质主播：

1. 主播所在国家或地区已经开放优质主播申请，开放范围以平台后台配置和申请页面为准。
2. 主播按照平台申请入口提交所需资料及展示视频。
3. 主播愿意在资格生效后完成每周直播要求，并遵守本指南中的直播规范。

申请期间如被平台巡查发现低质量或违规直播，平台会保留记录并用于综合审核，影响申请通过结果；申请期记录不计入尚未开始的正式资格周期警告次数。

---

## 二、怎样申请和生效

1. 在平台开放的国家或地区进入优质主播申请入口。
2. 按页面要求提交申请资料和展示视频。
3. 平台持续进行资格审核，不限制只能在某个固定日期审核。
4. 审核通过后，资格从下一个周一开始生效。

例如：主播在本周二审核通过，优质主播资格从下周一开始生效。这样每名主播都从一个完整的周周期开始考核。

---

## 三、优质主播有什么权益

### 每周15美元薪资

- 优质主播完成本周期直播要求，并且没有触发取消奖励处理，可获得每周15美元优质主播薪资。
- 优质主播资格、直播任务和薪资均按周结算。
- 每个结算周期为UTC+8时区的周一00:00至周日24:00。
- 周期结束后，平台在下一个周期的第1至第2个自然日内完成综合核算和薪资发放。

例如：1日至7日为一个完整结算周期，平台将在8日至9日内完成该周期薪资的核算与发放。

如果主播在本周期内触发取消奖励处理，本周期的优质主播薪资不予发放；进入下一个周期后恢复正常奖励资格，并根据下一周期的完成情况重新核算。

---

## 四、每周必须完成什么

### 1. 完成高峰时段直播

- 高峰时段以主播所在国家首都当地时间20:00—24:00为基准。
- 平台会根据国家或地区换算成UTC+8配置，主播以页面实际展示的高峰时段为准。
- 例如：某国家或地区的后台配置为UTC+8的19:00—23:00，对应其首都当地时间20:00—24:00。

### 2. 达到有效直播时长和天数

- 每天须在高峰时段内完成不少于120分钟的有效直播。
- 每周须完成至少6个有效直播日。
- 一个有效直播日，是指当天在高峰时段内完成不少于120分钟的有效直播。
- 黑屏、静音、挂机或其他低质量直播时长，不计入有效直播时长。

### 3. 保持申请时的综合表现

高峰时段的直播表现应与申请时上传的视频保持一致。平台会结合主播本人、形象状态、内容质量、互动状态和才艺表现等进行综合判断，不以某一个单项决定。

## 五、直播时必须做到

| 必须做到 | 具体要求 |
| --- | --- |
| 保持良好形象 | 直播期间必须化妆，保持整洁、得体的形象和适合直播的状态 |
| 主播本人出镜 | 主播本人应持续处于有效画面中，不得由他人代播 |
| 保持正常声音和画面 | 画面清晰稳定、无遮挡，声音可以正常收听 |
| 持续提供内容 | 持续聊天、表演、讲解或展示其他有效内容，不能只等待用户进入 |
| 欢迎进入房间的用户 | 主动与进入直播间的用户打招呼 |
| 回应用户礼物 | 收到礼物后进行口头感谢或点名感谢 |
| 关注直播用户 | 面向用户进行直播，不长时间看手机或处理无关事情 |
| 及时处理异常 | 发现黑屏、无声、网络或设备异常时立即修复；无法恢复时结束直播 |
| SANO独家直播 | 在SANO开播期间，不得同时在其他平台直播 |

## 六、哪些事情不能做

| 违规行为 | 主播需要知道的判断方式 |
| --- | --- |
| 长时间不说话 | 主播虽然出镜，但没有语言、表演、内容展示或用户互动 |
| 静音直播 | 直播持续没有有效声音，用户无法正常收听 |
| 躺床直播、躺播或睡播 | 主播处于躺卧或睡眠状态，不能正常提供直播内容 |
| 长时间离开镜头 | 主播离开有效画面达到2分钟会触发平台检测和审核 |
| 黑屏直播 | 画面持续黑屏或没有可识别内容 |
| 空等用户 | 以等待用户进入为由，不进行内容展示或互动 |
| 仅播放音乐 | 只播放音乐，主播本人没有演唱、讲解或其他实际参与 |
| 长时间看手机 | 持续操作其他设备，没有面向直播用户提供内容 |
| 画面长期异常 | 画面模糊、黑屏、严重抖动或被遮挡，影响用户正常观看 |
| 挂播 | 只维持开播状态，没有真实、持续的内容或互动 |
| 多平台同时直播 | SANO开播期间，同时在其他平台直播 |
| 高峰表现明显不符 | 高峰时段的综合表现与申请视频明显不一致 |

### 关于“长时间”的说明

- 除“离开镜头达到2分钟触发检测”外，平台不会用同一个固定时长判断所有行为。
- 看手机、不说话、等待用户和画面异常等行为，会根据持续时间、直播内容、互动状态及对观看体验的影响综合判断。
- 20秒以上可以作为系统检测的参考，但不代表达到20秒就自动处罚。
- 短暂喝水、调整设备或处理突发问题，不会只凭一个画面直接认定违规；平台应结合连续直播记录判断。

## 七、多人直播中的责任

### 房主必须做到

- 持续主持、表演或组织互动，保证房间有明确的主要内容。
- 关注麦上嘉宾的声音、画面和互动状态。
- 嘉宾离开画面或关闭摄像头超过30秒，或者持续不说话、不互动时，及时提醒或调整。
- 嘉宾长期低活跃，或者出现躺播、睡播、黑屏、静音或挂机行为时，及时提醒、调整展示或移出麦位。

麦上有多名嘉宾时，建议房主放大或突出正在有效互动的嘉宾麦位。此项属于优化观看体验的建议，不是强制要求，也不能单独作为违规处罚依据。

### 嘉宾必须做到

- 正常出镜，保证声音和画面可用。
- 进行真实的语言、表演或其他有效互动。
- 配合房主安排的直播内容和麦位管理。
- 不长期占用麦位却不说话、不出镜或不互动。
- 不出现本指南第六章列出的低质量直播行为。

### 责任怎样判断

- 嘉宾对自己的黑屏、静音、挂机、躺播或不互动行为负责。
- 房主对主要直播内容和麦位管理负责。
- 房主已经及时提醒、调整或移出异常嘉宾的，不因嘉宾的短暂异常直接判定房主违规。
- 房主发现嘉宾长期异常却不处理的，房主属于未履行管理责任。

## 八、违规后怎么处理

### 1. 先提醒主播整改

- 系统或运营发现轻微问题时，先向主播发送整改提醒。
- 主播收到提醒后立即改正并恢复正常直播的，本次不计为有效警告。
- 首次轻微问题原则上只提醒、不计次。
- 主播未整改、整改后频繁再次发生，或者违规经证据审核成立时，才计入有效警告。

### 2. 有效警告和处罚

| 本周期有效警告次数 | 处理结果 |
| --- | --- |
| 第1次 | 警告一次，主播须立即整改 |
| 第2次 | 取消本周期优质主播奖励，当前即取消本周15美元薪资 |
| 第3次 | 取消优质主播资格，根据违规情况处理为普通取消或永久取消 |

### 3. 警告何时清零

- 有效警告按UTC+8时区的周一至周日累计。
- 进入下一个周周期后，本周期有效警告次数自动清零。
- 次数清零不代表删除历史记录。违规行为、证据和处罚结果会继续保留，并影响再次申请审核。

### 4. 资格取消后能否再次申请

- **普通取消：**资格取消满7天后可以再次申请。
- **永久取消：**不能再次申请优质主播资格。
- 再次申请不代表自动通过。平台会根据违规类型、严重程度、历史次数和整改情况综合审核。
- 直播质量规则之外的严重违规，可依据平台相应规则直接取消奖励、取消资格或永久取消资格。

---

## 九、平台依据什么判定

- 每个生效违规都会记录直播场次、发生时间、违规行为和对应证据。
- 主播与平台都可以查看生效次数及相关记录。
- 同一短时间内连续出现多个相关问题，原则上合并为一次有效警告。
- 长时间直播中频繁重复违规，可以依据各次行为的时间、间隔和证据记录为多次有效警告。
- 同一事件被系统、运营或多名用户重复上报时，应合并处理，不能重复处罚。
- 主播立即整改或首次出现轻微问题时，只提醒、不计入有效警告。

主播对判定有异议时，由运营与主播根据违规记录和证据进行沟通复核。复核确认不违规的，平台应撤销本次警告，并恢复由本次警告造成的奖励或资格影响。

## 十、主播每周自检

- [ ] 我的国家或地区已经开放优质主播资格。
- [ ] 我清楚平台显示的高峰直播时段。
- [ ] 我每天在高峰时段有效直播不少于120分钟。
- [ ] 我本周完成至少6个有效直播日。
- [ ] 我的综合表现与申请视频保持一致。
- [ ] 我保持良好形象、持续出镜并提供内容。
- [ ] 我主动欢迎用户，并及时感谢礼物。
- [ ] 我没有黑屏、静音、挂机、躺播或长时间离镜。
- [ ] 我没有在其他平台同时直播。
- [ ] 多人直播时，我已经履行房主或嘉宾责任。

以下内容确认后，本讨论稿才能作为最终主播规则发布：

1. 优质主播申请入口的名称、所在页面和需要提交的完整资料。

3. 普通取消和永久取消分别适用于哪些违规情形。
4. 运营与主播无法就复核结果达成一致时，最终处理机制是什么。
